# 💄 Pariha Beauty Care

## 📖 Overview

Pariha Beauty Care is a web-based Beauty Salon Management System developed using PHP and MySQL. The system allows customers to view beauty services, salon packages, team members, gallery images, and book appointments online. It also provides an admin panel to manage salon operations efficiently.

The main objective of this project is to simplify salon management, improve customer experience, and provide an easy online appointment booking system.

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/SnehaVaghasiya04/Pariha-Beauty-Care.git
```

### 2. Database Setup

- Create a MySQL database.
- Import the provided SQL file.
- Configure database connection settings.

### 3. Run the Project

- Start Apache and MySQL using XAMPP.
- Place the project folder inside `htdocs`.
- Open browser and run:

```text
http://localhost/pariha_beauty_care
```
